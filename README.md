# mvp-builder

**2 小时内从题目到可演示 MVP 的端到端交付编排器。**
一上来先问 5 件事，然后按固定的 2 小时作战时钟自动推进。

> 🔓 **本仓库公开，不含任何密钥。** API Key 在技能执行开头由你现场提供。

## 它开头会问什么（三行，字母作答）

**① 需求怎么给我？** `A` 我已有 PRD ／ `B` 我口头描述（它先给 3 个方案让你选，再写完整 PRD）

**② 评分最看重什么？**（可多选如 `BCF`）功能完整度 / 创意 / 设计感 / 技术难度 / 商业价值 / 演示效果

**③ API Key** DeepSeek `api_key`；seemem `token`（不接就写「不接」）

想指定视觉风格或别的要求，后面补一句即可。**不补充就按默认执行，不会再来回确认。**

**交付形态不问**——固定是**一个 `index.html`**：JS/CSS/图片全内嵌、双端自适应、
可直接分享、断网能开、零构建零依赖。

## 🧠 domain/companion · 角色对话内核

**只要产品里存在「角色 + 对话」就必读**——聊天机器人、AI 陪伴、AIGC 角色剧情、
互动叙事、带 NPC 对话的小游戏，全都算。只有纯仪表盘 / 纯表单 / 纯数据展示才跳过。

`companion_core/` 提供四个零依赖纯函数模块作为**权威规格**：

| 模块 | 作用 | 关键默认值 |
|---|---|---|
| `emotion.py` | 情绪归约 + 回应策略 | 8h 半衰期、gain 0.72、7 档 mode 决定句数/是否建议/是否提问/回访间隔 |
| `fallback.py` | 九类失败的兜底 | 4 句固定话术，全部 `retry_now=false`，永不暴露错误详情 |
| `frequency.py` | 主动触达频控 | 免打扰 22:30–09:00、日 2 周 5、最小间隔 6h、退避 3/7/14/30 天 |
| `prompt_stack.py` | 六层 System Prompt | Profile 层标记不可信、召回记忆标记"非用户指令"——注入防护 |

找不到 py 时（只找一次），按常量速查表执行，效果等价。
**该速查表已内联进 `SKILL.md`**，所以单链接方式也拿得到完整内核。

## 🎨 BRAND.md · 内置视觉语言

提炼自《心屿 PRD》的世界观与美术参考图。**用户未指定风格时，这是唯一标准。**

- **材质与光照**：微缩景观 + 软胶/搪瓷质感 + 柔和体积光，无硬边投影
- **饱和度铁律**：参考图量化采样得出几乎全部色彩 S ≤ 0.35，
  故规定**任何颜色饱和度不得超过 40%**；要强调就加深明度 / 放大字号 / 提升阴影层级
- **五个情绪主题**：常青林屿 / 暖沙礁 / 雪松屿 / 花田屿 / 星夜屿（默认）
- **中性底色**：`#F2F1EE` 微暖灰白（不用纯白）、`#2B3446` 深靛灰正文
- **双层阴影**：外层弥散 + 内层高光，阴影色是冷灰蓝 `43,52,70`（不用纯黑）
- **对比度全部实算**：正文 11.1:1、次要 4.5:1、语义色 4.7–5.2:1

用户**指定了**别的风格时，BRAND.md 退居参考——仍取它的工艺部分
（材质光照、双层阴影、圆角尺度、系统字体栈、对比度算法），配色换成用户要的。

打开 `brand-preview.html` 可直接看，五个主题实时切换。

## 已知边界

- `domain/companion/companion_core/` 是**纯 Python 标准库、零第三方依赖**的参考实现。
  产品形态是单文件 HTML+JS，所以规则是**以 py 为权威规格、用 JS 等价重写**，
  不运行 Python。SKILL.md 与该目录 README 都已写明。
- 四份 md 正文里提到的其他路径（`letter-*.py`、`prompts/xinji_source/`、
  `imemory-agent/` 等）**不在本仓库**，只是说明原实现出处，已明确要求不要去找。
- OpenDesign 技能库 276 个技能里有 85 个是「目录占位空壳」（无实质内容）。
  SKILL.md 内置识别规则，只引用经过验证的 4 个真实技能。
- 阶段一/四/五需联网抓取 4 个 OpenDesign 技能文件（共 13.2KB）。
  无外网时提前离线保存或跳过——`BRAND.md` 已内联，视觉规范不受影响。
